Pediatric CME and Webinars

Upcoming Events, Archive, and Credits

Open in PediAid → ← All tools

1 What is the Pediatric CME and Webinars?

CME & Webinars is a backend-backed events browser for pediatric conferences, webinars, workshops, and courses, replacing what its own code comments describe as 'the old hardcoded PEDICON and NeoUpdate static cards.' Events are fetched from the app's API and split into tabs by type, and signed-in users get an additional 'My posts' tab to track events they've submitted for community review.

2 When to use it

  • Browsing upcoming pediatric conferences, webinars, workshops, and courses in one place.
  • Filtering events by type using the Conferences / Webinars / Workshops / Courses tabs.
  • Opening an event's detail screen before deciding whether to register.
  • Sharing a CME, webinar, workshop, or conference with the PediAid community by posting it (signed-in users).
  • Tracking the review status of a self-submitted event in the 'My posts' tab.

3 Formula & method

Events are fetched from the app's events API and filtered client-side into four public tabs by event type. A floating 'Post event' button, visible when signed in, opens a submission screen; every submitted event is reviewed before going live, and its status is shown as a badge — Published, Pending review, Needs changes, Rejected, or Cancelled — in the 'My posts' tab. If the backend can't be reached, the screen falls back to showing sample events with a banner: 'Showing sample events — live listings will load once the server is back online.'

4 Frequently asked questions

What event types does CME & Webinars list?

Four, shown as tabs: Conferences, Webinars, Workshops, and Courses.

Can I submit my own CME event?

Yes — signed-in users can tap 'Post event' to share a conference, webinar, workshop, or course with the community.

How do I check if my submitted event was approved?

Open the 'My posts' tab, which shows a status badge: Published, Pending review, Needs changes, Rejected, or Cancelled.

Do I need to sign in just to browse events?

No — browsing the public tabs doesn't require an account. Signing in is only needed to post an event or view 'My posts'.

What happens if the events server is unreachable?

The screen shows sample events with a banner noting that live listings will load once the server is back online.
